# Level roadmap

Level 1.0 establishes the local adaptive engine, four modes, site memory, tab control, privacy model, and store-ready product surface.

## 1.1 — Calibration and evidence

- Add an optional guided calibration sequence using packaged test signals.
- Expand the DSP fixture suite with reproducible speech, silence, and transient envelopes.
- Add visible limiter-reduction metering.
- Add import/export for Level settings and website profiles.

## 1.2 — Smarter speech

- Evaluate a local speech-presence detector that requires no model download.
- Make Dialogue mode adapt its presence lift to programme confidence.
- Add mono-centre emphasis for compatible stereo material.

## 1.3 — Control everywhere

- Add a compact side-panel control surface where supported.
- Add optional named user presets.
- Add an accessible high-contrast visual theme.

## Research track

- Perceptual K-weighted measurement without claiming formal broadcast compliance.
- True-peak approximation with bounded worklet cost.
- Cross-tab output matching using local session-only statistics.
- Platform-safe ways to reduce activation friction without weakening Chromium's consent boundary.

Features enter a release only when they preserve Level's single purpose, local-only audio guarantee, and store-policy compliance.
