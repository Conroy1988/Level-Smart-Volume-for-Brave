# Security policy

## Supported versions

Security updates are provided for the latest published version of Level.

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy vulnerability. Use GitHub's private vulnerability reporting feature for this repository and include:

- the affected Level version;
- the browser and operating system;
- clear reproduction steps;
- the impact you believe is possible.

Level contains no remotely hosted code and sends no browsing or audio data to a server. Reports that demonstrate a breach of those guarantees will be treated as highest priority.
